# Indus Weaves Semantic Product Search

## Project Overview
An AI-powered semantic product search system for Indus Weaves Exports. It helps users find textile products from a catalog using natural language queries.

## Project Goals
- Natural language product search
- Product embeddings
- Vector search
- AI-powered retrieval
- Fast and accurate product results

## Technologies
- Python
- n8n
- FastAPI
- Gemini API
- Embeddings
- Vector Search

## Project Status
Task 1: n8n workflow setup with Webhook, Google Sheets, AI classification, and error handling.
